# syedyusuftalha.github.io

Personal site of **Syed Yusuf Talha**, AI & Software Engineer based in Dubai.

🌐 Live at **https://syedyusuftalha.github.io**

A plain static site (HTML, CSS and a little JavaScript) hosted on GitHub Pages. There's no build step: edit `index.html`, commit, and the site updates within a minute or two.

- `index.html`: all page content
- `assets/style.css`: styles, including light and dark themes
- `assets/main.js`: theme toggle, scroll animations and nav highlighting
- `assets/og-image.png`: the preview image shown when the link is shared on LinkedIn
